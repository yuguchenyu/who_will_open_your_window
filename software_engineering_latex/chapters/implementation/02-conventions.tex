\subsection*{源码组织与编码规范}
修改一项业务时，从\DesignCode{server.mjs}中的路由可以找到相应的业务函数。认证、匹配、通信和媒体分别放在\DesignCode{lib/}下，页面与浏览器交互集中在\DesignCode{public/}。各模块通过\DesignCode{import/export}引用所需函数。

前端共12个源文件、7679行，后端共15个源文件、3204行，合计10883行；去除空行后为10485行。统计范围包括\DesignCode{public/}中的JavaScript、HTML、CSS，以及\DesignCode{server.mjs}和\DesignCode{lib/}中的后端代码，注释计入行数。测试、文档、图片和依赖另行存放。

例如增加回复风格时，服务端先检查参数是否在允许范围内，浏览器再按所选风格刷新建议。请求字段、页面读取和测试中的模拟返回需要一起调整。涉及异步请求时，在代码中说明结果何时可以采用，便于排查旧结果覆盖新页面的问题。
