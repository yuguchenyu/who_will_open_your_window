\ReportUnnumberedChapter{任务书}

\section*{一\quad 总体要求}
\begin{enumerate}
  \item 综合运用软件工程的思想，协同完成一个软件项目的开发，掌握软件工程相关的技术和方法；
  \item 组成小组进行选题，通过调研完成项目的需求分析，并详细说明小组成员的分工、项目的时间管理等方面。
  \item 根据需求分析进行总体设计、详细设计、编码与测试等。
\end{enumerate}

\section*{二\quad 基本内容}
根据给出的题目任选一题，自行组队，设计与开发的软件过程必须包括：
\begin{enumerate}
  \item 问题概述、需求分析：正确使用相关工具和方法说明所开发软件的问题定义和需求分析，比如 NABCD 模型，Microsoft Visio，StarUML 等工具（20\%）；
  \item 原型系统设计、概要设计、详细设计：主要说明所开发软件的架构、数据结构及主要算法设计，比如墨刀等工具（35\%）；
  \item 编码与测试：编码规范，运用码云等平台进行版本管理，设计测试计划和测试用例（30\%）；
  \item 功能创新：与众不同、特别吸引用户的创新（10\%）；
  \item 用户反馈：包括用户的使用记录，照片，视频等（5\%）。
\end{enumerate}
