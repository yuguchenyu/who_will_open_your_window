# 软件工程项目报告原样式 LaTeX 版

本版以所提供 Word 文件的**实际直接格式**为依据，保留原文的文字、字号、颜色、粗体、下划线、段落层次、图表尺寸和手工目录。它用于保留参考样本的外观和内容，不会把其中的格式批注自动删除。

## 打开和编译

1. 完整解压，保留 `content/`、`assets/` 和 `fonts/` 目录。
2. 直接打开 `main.pdf` 查看本次编译后的效果。
3. 编辑 LaTeX 时，以 `main.tex` 为主文件，使用 **XeLaTeX** 编译。
4. 本机可执行 `latexmk -xelatex main.tex`；也可运行 `build.bat`（Windows）或 `bash build.sh`（macOS / Linux）。

本工程使用标准 `fontspec`、`xeCJK`、`geometry`、`xcolor`、`graphicx`、`array`、`booktabs`、`fancyhdr`、`etoolbox`、`xfp`、`hyperref` 宏包。常用的完整 TeX 环境包含这些宏包；若报缺包，请安装报错中对应的宏包。不要使用 pdfLaTeX 编译。

本次已使用 XeLaTeX 完成编译，并逐页检查了生成的 PDF。包内的 `main.pdf` 由这套源文件生成。

## 本版恢复的原稿细节

- 保留红色字体与字号说明，并放回原来的段落；封面组号说明仍在组号行，使用原深红色。
- 封面学号与姓名保持原来的八行结构、缩进和下划线，保留原空白填写区。
- 保留原目录的蓝色/黑色文字、点引导线、全部示例条目与页码；不替换为自动目录。
- 保留各段自己的行距：1.25、1.5、2、1.35 倍及固定 15、22.5、23 pt 等，不统一成一种行距。
- 保留原页眉字间空格、黑色横线、蓝色页脚线、前置页罗马数字及正文“页码”占位。
- 保留 5×4 表格、原列宽及特殊横线；图片采用原稿中的显示尺寸、裁切及位置。
- 保留原文中的 `□`、省略号、分页提示、粘连的“1.3 1.4”和重复的“5.1”等字样。参考样本中的文字没有被擅自纠错或补写。

原文件以空段落推动目录换页；LaTeX 在目录开始处固定了该页界，避免目录标题落在任务书页尾。第2.3节的标题与短说明保持在同一页，避免替代字体导致标题与说明分离。其余原有的显式分页、分节和空段落已保留。

## 字体与分页的准确性说明

原 Word **没有嵌入字体**。本工程优先使用本机已安装的宋体、黑体、楷体、仿宋、华文中宋和 Times New Roman；缺少时使用包内的 Fandol 与 TeX Gyre Termes。包内 PDF 在开源替代字体下生成，字体许可见 `fonts/`。

替代字体与 Windows 原字体的字形、字宽和字体行高并不完全一致。Word/WPS 与 TeX 的行距、标点挤压和分页算法也有差异，因此本版恢复的是原稿内容和排版属性，**不能保证与某一台电脑上的 Word 逐像素一致**。自动行距按原倍数映射，并通过 `word-layout.sty` 中的 `\WordLineScale` 校准基础行高；固定值行距直接采用原数值。本次预览为13页，这个页数并不证明每一页都与原 Word 的页界相同。

如果你的电脑安装了原文件所用的字体，重新编译时会优先使用它们；字形更接近原稿，但自然换行和总页数可能随之变化。字体选择集中在 `font-settings.tex`，没有附带或冒充任何商业字体文件。

## 如何修改内容

每个 `content/*.tex` 文件按原段落顺序排列，并带有“原文段落”注释。为了保留同一行中的混合字号、颜色和字体，文字使用以下形式：

```latex
\WordRun{Times}{Song}{12}{0}{0}{000000}{0}{这里是可编辑的文字}
```

最后一对花括号内是正文。前面的参数依次为西文字体、中文字体、字号、粗体、斜体、十六进制颜色和下划线。一般只修改最后一项；`\WordSpace{数字}` 用于保留原文的连续空格。

`\begin{WordParagraph}` 后面的八个参数控制对齐、基础字号、行高、左右缩进、首行缩进和段前段后距离。只改文字时通常不需要修改它们。需要填封面时，可在相应下划线运行的最后一项中填写内容，适当减少其后的空格。

由于本版保留的是原样本的手工目录，正文增删后，目录条目和示例页码需要自行更新。这与自动编号的正式报告模板用途不同。
