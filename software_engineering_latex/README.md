# 谁能打开你的窗：软件工程项目报告

## 正式报告

正式报告唯一入口是 `report.tex`，交付文件是 `report.pdf`。当前入口载入封面、任务书、目录、第3章和紧凑附录“设计补充资料”；第1、2、4–6章保持注释。第1、2章保留为可复用源码，第4–6章及旧大附录源码仅供备查，不进入本次 PDF。采用自动目录、章节及图表编号，前置页用罗马页码，正文用阿拉伯页码。

```powershell
# 在本目录执行
latexmk -xelatex -interaction=nonstopmode -halt-on-error -file-line-error report.tex
# Windows 也可运行 .\build.bat，固定编译 report.tex
```

macOS / Linux 可不带参数运行 `bash build.sh`。所有环境均使用 XeLaTeX，不能使用 pdfLaTeX。字体由 `reportstyle.sty` 管理，优先采用本机宋体、黑体、仿宋和 Times New Roman，缺失时回退包内开源字体，详情见 `fonts/README.md`。

| 文件 | 用途 |
|---|---|
| `report.tex`、`report.pdf` | 正式入口及报告 |
| `chapters/` | 任务书、封面、正文及附录源码；是否编译以 `report.tex` 为准 |
| `chapters/design/` | 第3章按主题拆分的20份正文；编辑索引见该目录的 `README.md` |
| `metadata.tex` | 题目、课程及待填写个人资料 |
| `reportstyle.sty` | 正式报告字体、排版、目录、图表及代码 |
| `fonts/` | 开源回退字体及完整许可，须保留 |
| `assets/hust-logo.png` | 正式封面使用的校名图，须保留 |
| `assets/report/` | 五张隔离演示截图、回归输出、源码统计及 `layout-check.txt` 排版核验记录 |
| `scripts/capture-report.mjs` | 内存数据库、模拟模型的截图生成工具 |
| `待补充资料.md` | 封面、实际分工、个人体会和真实反馈清单 |

报告明确区分当前源码、归档隔离回归、历史测量和未验证事项。既有回归归档记录120项通过，完整输出见 `assets/report/regression.txt`，环境及工作区摘要见 `assets/report/provenance.txt`；本次仅更新文档，不重新运行业务测试。16组历史性能数据引用2026-10-31记录，仅留作备查，不作为本次重测或真实模型耗时，不重复收入正式紧凑附录。五张截图来自隔离演示账号，真人对象的展示立绘在测试库中使用项目自带插画，不是实际用户上传的私有素材。

个人资料和真实用户反馈尚待提供，报告保留明确标记，没有编造团队经历或访谈。填写后重新编译；成员槽位数量需要按实际人数调整。

如需重新生成截图，在项目具备原有 Playwright 测试工具和 Chrome 的情况下运行 `node scripts/capture-report.mjs`。脚本不读取 `.env`，不连接真实模型、不打开日常数据库，结束时关闭测试资源。图片生成质量、真实模型兼容性和完整浏览器业务回归不是五张截图检查的证明范围。

## 设计补充资料

正式附录入口为 `chapters/appendix.tex`，原始附录已逐行注释，当前设计补充资料直接写入该文件。仅设一个附录章，以节划分摘要资料。本轮实测5页，符合最多6页的要求，不声称提供全量接口或每一个字段。冗余的兼容入口已删除。

| 内容分组 | 范围 |
|---|---|
| 接口摘要 | 按业务分组列代表输入、输出及错误类型，不复制全量路由 |
| 数据表与关键字段索引 | 覆盖18表的主键、关键外键和职责，仅列设计必需字段 |
