# 报告待补充资料

报告技术正文依据当前项目源码、隔离回归、历史验证记录和演示截图完成。以下资料尚未提供，不编造为已完成事实。

## 必填个人信息

- 在 `metadata.tex` 填写专业班级、组号、指导教师、报告日期、成员姓名与学号。
- 模板保留四组成员槽位，实际人数待确认；不需要的行应按真实人数调整。
- 第1章：填写真实责任范围、完成时间、贡献证据和实际计划；不把建议分工当作真实分工。
- 第6章：由各成员独立填写任务、实际困难、定位过程、解决方法、验证结果和反思。

## 真实用户反馈

- 第5章提供了试用任务及反馈表，尚未实际组织试用。
- 补充经参与者同意的匿名使用记录、原始反馈，以及课程要求的照片或视频。
- 如统计完成率、开口压力或满意度，补充统一量表、样本来源、日期和统计口径。
- 演示账号截图和自动化测试不是用户调研，不能替代真实反馈。

## 可选补充证据

- 真实仓库平台的签入截图。报告使用本地 Git 记录，不使用模板的 Gitee 示例图。
- 真实模型兼容性、生成质量与人工评估；本次仅使用模拟模型，未调用真实密钥。
- 高负载、无障碍及完整浏览器业务回归。历史性能明确标注日期，不作为本次重测。

## 提交前检查

1. 搜索正式章节和元数据中的“待填”“待补充”，据实完成必填部分。
2. 按实际成员数量调整封面和分工表。
3. 使用 `latexmk -xelatex report.tex` 重新编译并检查目录及分页。
4. 提交 `report.pdf`，不要误用原复刻模板的 `main.pdf`。
